# 🏥 Customer Complaint AI System

AI-powered Customer Complaint Management System for pharmaceutical industry.

## 🚀 Tech Stack
- **Frontend**: React + Redux + Vite
- **Backend**: Python + FastAPI
- **AI Agent**: LangGraph + Groq (gemma2-9b-it)
- **Database**: MySQL

## ⚙️ Setup Instructions

### Backend
```bash
cd backend
pip install -r requirements.txt
uvicorn main:app --reload
```

### Frontend
```bash
cd frontend
npm install
npm run dev
```
